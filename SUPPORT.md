## Why support Talvoro?

Optional support helps sustain work such as:

| Area | What support helps with |
| --- | --- |
| Development | New capabilities, maintenance, refactoring, and compatibility work |
| Quality | Automated tests, regression coverage, and release validation |
| Security | Security reviews, hardening, advisories, and supported fixes |
| Documentation | Installation, upgrade, recovery, development, and verification guides |
| Release engineering | Reproducible builds, checksums, signatures, provenance, and packaging |
| Infrastructure | Project services and tooling required to maintain Talvoro |

## No obligation

You never need to financially support Talvoro just to use the supported Community edition.

If you cannot or do not want to contribute financially, useful bug reports, documentation improvements, testing, and constructive feedback are also valuable ways to help the project.
